# 👨‍💻 Developer Survey Data Analysis

## 📌 Objective
To analyze global developer trends using the Stack Overflow Developer Survey dataset
and extract meaningful insights related to technologies, salaries, and work patterns.

---

## 🧾 Dataset
- Source: https://survey.stackoverflow.co/
- Description: Annual survey data collected from developers worldwide
- Note: Dataset not uploaded due to GitHub size limits

---

## 🔍 Analysis Performed
- Data cleaning and preprocessing
- Analysis of most-used programming languages
- Developer salary trends
- Education level vs employment
- Remote work trends

---

## 🛠 Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 📊 Key Insights
- Python is among the most widely used languages
- Developers with higher education tend to earn more
- Remote work adoption has increased significantly
